# 6V JGB37-520：24V → LM2596 → 6V，保留原 5V 繼電器控制

> **新增伺服替換／辨識測試版：請見 [伺服接線圖與 GPIO1 測試說明](./WIRING_SERVO_TEST.md)。本頁保留兩線減速馬達設計供對照；伺服的電流及控制方式另行確認，不直接套用本頁馬達數據。**

本版把昨天的 24V 馬達支路改成 **既有 24V 電源 → LM2596 可調降壓模組 → 6.0V → K2 COM/NO → 6V 馬達**。K2 仍是 HW-307／JQC3F-05VDC-C、5V 低電位觸發模組；K2 VCC、GPIO2 的 NPN 介面、原 K1/GPIO7、LCD 與感測器接線保留。

你已確認馬達改為 **JGB37-520、6V、200rpm**，後續提供商品數據：6V 堵轉電流約 **1.5A**、堵轉轉矩約 **1.3kgf·cm**、額定轉矩約 **0.34kgf·cm**。本頁新增第 4.1 節，依這些數字作條件重算；商品數據尚未確認與手上實物完全相同。**目前仍不能保證手上 LM2596 模組能啟動馬達，也不能完成 D1 的熱驗證或決定保險絲安培值**。同型號的不同電壓繞組不能假設電流相同，亦不能按 6/24 比例推算。

LM2596 圖中是有 **IN+、IN−、OUT+、OUT−** 的完整模組，不是裸 IC 的五隻腳。以實物端子絲印辨識，不能依圖上的左右位置猜測。

| M-03 | 24V 負極 | U1 IN− | 輸入負極 |
| M-04 | U1 OUT+ | F5 輸入 | **先調整並量測為 6.0V** |
| M-05 | F5 輸出 | K2 COM／公共 | **COM 現在是 6V，不是 24V** |
| M-06 | K2 NO／常開 | M2 正極 | K2 吸合才供電；NC 留空 |
| M-07 | M2 負極 | U1 OUT− | 以能承受馬達電流的線直接回模組，不經 ESP32 GND 細線 |

## 3. 電晶體及電阻重算

計算假設：ESP32 GPIO 標稱 3.3V，最低檢查值 2.64V；K2 電源以 5V±5% 檢查；三顆電阻誤差 ±5%。這些是設計假設，不是現有硬體的量測結果。

馬達的 6V 不進入這段電路。Q2 截止時只承受約 5V，導通時只處理 K2 IN 加 R3 電流；**馬達啟動／堵轉電流不流經 Q2 或 R1/R2/R3**。

以 S9014 的基極壓降 **1.0V 作設計檢查假設**、強迫增益 10、目標 IC≤10mA：

```text
目標 IB ≥ 10mA / 10 = 1.000mA

IB(min) = (2.64 − 1.0)/(1500 × 1.05) − 1.0/(47000 × 0.95)
        = 1.019mA

GPIO 標稱電流 = (3.3 − 1.0)/1500 = 1.533mA
IB 標稱值 = 1.533 − 1.0/47000 × 1000 = 1.512mA

R1 標稱值上限（滿足上述目標）
  = (2.64 − 1.0)/[(0.001 + 1.0/44650) × 1.05]
  ≈ 1.528kΩ → 原 1.5kΩ 可保留
```

onsemi **SS9014** 的資料表列出 VBE(sat)≤1.0V、VCE(sat)≤0.3V 的測試點是 **IC=100mA、IB=5mA、25°C**；不是本設計 10mA 的同一測試條件，也不是未知廠牌 S9014 的保證。上述 1.019mA 是驅動預算檢查；接線後仍須量測 IN 足夠低且 K2 可靠吸合，不能直接宣稱實物在此工作點保證 0.3V。

若保留原 **onsemi 2N3904**，沿用其 10mA/1mA 測試點的 VBE(sat)≤0.85V 檢查，IB(min)≈**1.117mA**，亦無須更換 R1。

R3 與模組 IN 共用 Q2 的吸入電流預算：

```text
R3 最大電流 = 5.25/(4700 × 0.95) = 1.176mA
K2 IN 可用電流預算 = 10 − 1.176 = 8.824mA
```

K2 IN 的實際電流仍未知，不能拿線圈電流或舊 ICShop 模組的 5mA 代替。若實測 Q2 總 IC>10mA，須重算介面。

| 元件 | 保守功耗計算 | 結果 | 原 0.25W 是否保留 |
|---|---|---|---|
| R1 | 3.3²/(1500×0.95)，保守忽略 B-E 壓降 | **7.64mW** | 是 |
| R2 | 1.0²/(47000×0.95) | **0.0224mW** | 是 |
| R3 | 5.25²/(4700×0.95) | **6.17mW** | 是 |

以 IC=10mA、VCE=0.3V、VBE=1V 和上述標稱 IB 作條件估算，Q2 耗散約 **0.3×0.010 + 1.0×0.001512 = 4.51mW**。這不是實測或全溫度最壞值。停止時目標 IN≥4.5V 且釋放；啟動時目標 IN≤0.3V 且吸合，均需在實物上確認。

## 4. 馬達續流二極體 D1

**保留 1N5408 作候選，不因 24V 改 6V 就必須換型號；是否能沿用取決於斷電時電流及溫升。** Vishay 額定為 3A／1000V；3A 有引腳長度、引腳溫度條件，不能直接當成任意模組佈線下的連續電流保證。

本圖保留昨天的條件：**最大斷電瞬間電流 I0≤2A、繼電器低頻啟停，續流波形及溫升另驗證**。2A 是選型前提，並非這顆馬達的規格或已測數值。

```text
正常反向偏壓約 6V：1000V / 6V ≈ 167 倍（只比較標稱電壓）
若最大斷電電流為 2A：3A / 2A = 1.5（僅額定電流比較）
以 VF=1.2V 作條件估算：2A 時斷電初始功耗約 2.4W，之後衰減
線圈儲能 EL = ½ × L × I0²
平均功耗 PD = 啟停頻率 f × ∫VF(t) × iD(t) dt
```

VF=1.2V 是原廠在 3A、25°C 的規格；以上 2A 的初始功耗是估算。由於 L、I0、續流時間、頻率未知，目前不能給出實際平均瓦數或保證溫升。若可能在 >2A 時切斷，超出本圖採用的選型前提，應先重算 D1；不代表任何 >2A 脈衝必然使它損壞，也不直接以更大二極體代替整體驗證。

**有環 K 接馬達＋（K2 NO 後），無環 A 接馬達−**。LM2596 板上本來的開關續流二極體位於降壓電路內，不能代替這顆跨在馬達兩端的 D1。K2 斷開後 D1 必須仍與馬達構成完整續流路徑，所以不可把 D1 正端移到 K2 COM 或 U1 OUT+。

### 4.1 依補充的 6V／1.5A 商品數據重算

**這是依你提供的商品資料計算，並非實物量測。** [Probots 的 6V／200rpm 商品頁](https://probots.co.in/jgb37-520-dc6v-200-rpm-miniature-speed-reduction-gear-dc-motor.html)確實列出 1.5A 堵轉電流、1.3kg·cm 堵轉轉矩及 0.34kg·cm 額定轉矩。此處將轉矩單位解讀為 kgf·cm。該頁的 50mA 標為「Rated Current」，不能直接當成已驗證的額定負載電流，也不能和另一廠牌的 50–150mA 空載電流混用。

你提供的 [Precision Mini Drives 頁面](https://precisionminidrives.com/product/37mm-diameter-miniature-dc-gear-motor-nfp-jgb37-520-dc-6v-12v-24v)包含不同繞組與減速比，6V 表格的堵轉電流列為 2.2A；其中 200rpm 亦出現在不同電壓版本。因此本次不把這些不同來源的數據合併成同一顆馬達的保證規格。

按 **6V 堵轉約 1.5A、單方向、繼電器低頻啟停**，取切斷前電流 I0=1.5A 作估算。若實物或量測電流更大，須以新電流重算：

```text
二極體斷電初始電流約為 1.5A，不是空載的 50–150mA。
本圖 D1 設計檢查上限仍保留 2A，不因商品標示 1.5A 而縮小。
3A / 1.5A = 2.0：僅作額定電流數值比較，不是熱裕量保證。
3A / 2A = 1.5：對照原先採用的設計檢查上限。
```

| 候選 D1 | 原廠額定／測試數據 | 在 1.5A 斷電初始電流下的條件估算 | 判斷 |
|---|---|---|---|
| 原 Vishay **1N5408-E3/54** | 3A／1000V；VF≤1.2V 的測試點為 3A、25°C | 若以 VF=1.2V 計，初始 PD≈**1.80W** | 可保留作低頻續流候選，仍核對脈衝波形／溫升 |
| 替代 ST **1N5822** | 3A／40V；VF≤0.525V 的測試點為 3A、25°C | 若以 VF=0.525V 計，初始 PD≈**0.788W** | 較低壓降的候選；不是更高電流額定，尚未更改圖上 D1 型號 |
| **1N5288** | 定電流二極體，與上述整流二極體不同 | 不適用本處續流容量計算 | 不可代替 D1 |

上述 VF 都不是在 1.5A 及任意溫度下的實測值，兩個瓦數是斷電初始條件估算，**不是連續耗散、平均功耗或實際發熱的保證**。兩款 3A 額定皆有原廠散熱條件；40V 是反向耐壓，與 6V 標稱正常反向偏壓相比足夠，接線瞬變仍需抑制。1N5822 的較低 VF 也會改變電流衰減時間，不能只以初始瓦數完成熱設計。

Q2 的容量不按 1.5A 選，因為它不在馬達電流路徑上。第 3 節計算保持有效：

| 檢查 | 重算結果 |
|---|---|
| Q2 截止時 VCE | 正常控制供電約 5V，按假設上限檢查 **5.25V** |
| Q2 集電極電流預算 | **10mA**，其中 R3 最多約 1.176mA，留給 K2 IN 約 **8.824mA**，需實測 |
| S9014 驅動預算 | VBE=1V 假設下，R1/R2 誤差與 GPIO 電位檢查得到 IB(min)≈**1.019mA** |
| Q2 條件功耗 | IC=10mA、VCE=0.3V、VBE=1V、IB=1.512mA 時約 **4.51mW** |
| 參考 SS9014 絕對額定 | VCEO=45V、IC=100mA、PT=450mW（25°C）；非建議工作點，實物廠牌與散熱需核對 |
| 原電阻 | **R1=1.5kΩ、R2=47kΩ、R3=4.7kΩ，全部 0.25W／±5%，保留** |

參考 SS9014 的 0.3V 飽和規格不在本電路的同一工作點，且無法替未知廠牌 S9014 C331 作保證；須確認實際 IN 電位與吸合。若原先已使用 2N3904，亦不必因這次的 1.5A 馬達數據更換。

供電方面，6V×1.5A=**9W** 是堵轉時的輸入功率估算，不是可持續輸出的機械功率。U1 至少需應付實際啟動期間約 1.5A 的輸出需求；按效率 85% 作穩態示例，24V 輸入約 **0.441A**、模組損耗約 **1.59W**，不能用此輸入平均值代替輸出啟動容量驗證。

依同一組轉矩資料，6V 商品標示額定約 **0.0333N·m**、堵轉約 **0.1275N·m**。在固定電阻、忽略電刷壓降與限流的簡化啟動模型下，3V 堵轉轉矩約 0.65kgf·cm，1.2V 約 0.26kgf·cm；這些不是相應電壓下的可持續額定轉矩。最大啟動轉矩與持續工作能力仍須分開確認，不能長時間堵轉。

## 5. LM2596：24V 降至 6V 的容量計算

TI LM2596 可調晶片的工作範圍涵蓋此電壓轉換，資料表列 3A 輸出能力，但**你手上的整塊模組還受電感、板上二極體、電容、接頭、PCB 與散熱限制**。尚未取得模組規格，不能一概說它可持續輸出 3A。輸入側電容耐壓亦須適用 24V；建議核對至少 35V，並評估電源最高輸出及瞬變。

```text
理想占空比 D ≈ VOUT/VIN = 6/24 = 25%
輸出功率 POUT = 6 × IM
輸入平均電流 IIN ≈ (6 × IM)/(24 × η)
模組總損耗估算 Ploss ≈ POUT × (1/η − 1)
```

以下只以 **η=85% 作示例假設**，不是本模組的量測效率、保證值或建議工作電流：

| 馬達 6V 端電流示例 | 輸出功率 | 24V 端輸入平均電流估算 | 模組總損耗估算 |
|---|---|---|---|
| 1A | 6W | 0.294A | 1.06W |
| 2A | 12W | 0.588A | 2.12W |
| 3A | 18W | 0.882A | 3.18W |

這些是穩態功率估算，不能表示啟動瞬間電流波形。**即使 24V 輸入電流不到 1A，模組輸出仍可能承受 3A 或更大的馬達啟動負載。** F3 在輸入側、F5 在輸出側，不能照同一個數字選；還須協調電源短路能力、線材、模組限流及馬達啟動時間。

馬達啟動／堵轉需求可用 `Istall≈6V/Rcold` 作概念估算，但低阻繞組、電刷接觸與導線電阻會造成誤差，不能用目前未知的 Rcold 算出明確安培值。優先取得馬達規格或用適當限流設備量測啟動波形，避免刻意長時間堵轉。

若正常啟動需要超過模組可供的電流，可能掉壓、限流、反覆啟動或過熱；**不可只增大保險絲或更換 D1 解決**。若需求超過 LM2596 的 3A 輸出規格，應依實際啟動電流改選更高容量的 24V→6V 降壓器；低於 3A 也仍需驗證這塊板子的能力。

## 6. 調整與驗證順序

1. 關閉電源後改接馬達支路；原 110V 鼓風機保持斷電。馬達先不接，核對 U1 的四個端子，確認 24V 只進 IN 端。
2. U1 接 24V 後，在 **OUT+ 與 OUT− 間**用電表量測，轉動可調電阻直到 **6.0V**；不要只憑旋鈕圈數或板載顯示判斷。調整時避免工具碰觸其他焊點。
3. 確認 K2 VCC 仍為約 5V，COM 相對 OUT− 為約 6V；停止時 NO 不供馬達電力。確認 5V/24V 輸出允許共地，並測試啟停及重新上電時 K2 不誤動作。
4. 安裝 D1，核對有環端接馬達＋，再接 6V 馬達。使用已確認合適的電源電流限制與配線保護，先短時間、低機械負載測試；不要用電表電流檔直接跨接電源。
5. 量測啟動與預期負載運轉時 OUT 電壓、電流及模組溫升；空載能轉不等於滿載或堵轉適用。未確認的 F3/F5 安培值與模組啟動能力，不能由這張圖當成已完成選定。

## 7. 韌體與本次驗證範圍

本次**不需改程式、腳位或重新燒錄**。目前來源為 GPIO7 控制 K1、GPIO2 經 Q2 控制 K2；ToF1<101mm、ToF2<101mm、HC-SR04<65mm，讀值有效且連續三次符合才啟動；任一不符合即關閉。供電由 24V 改 6V 不改變此條件。

本次檢查圖面端子與二極體方向、重算控制電阻與條件功耗、產生 SVG/PNG 並目視檢查；未實測馬達、LM2596 或接點電流，未進行 110V 通電驗證。昨天的 24V 圖與文件保留供對照，現有 6V 馬達請依本文件及 6V 圖施工。
