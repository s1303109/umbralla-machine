# ESP32-S3 三感測器控制 110V 鼓風機：施工接線表

本文件對應 [高解析PNG接線圖](./wiring_110v_blower.png) 與 [可縮放SVG原圖](./wiring_110v_blower.svg)。它是端子級原理圖，不是假設 ESP32 開發板實體排針位置的「照片式接線圖」。施工時只依板上絲印、端子名稱和 GPIO 編號。

## 1. 已確認與尚未確認

已由照片或程式確認：

- 鼓風機：`150FLJ7-1W2`，110V、330W、60Hz、2800rpm。
- 電源：`S-50-5`，AC 110/220V 可切換，DC 5V/10A；端子由左至右為 `L`、`N`、`FG/PE`、`-V`、`-V`、`+V`、`+V`。
- 繼電器本體：`SLA-05VDC-SL-C`，外殼標示 1HP/120VAC；模組控制端為 `DC+`、`DC-`、`IN`，具有 `DC/JD` 兩個供電跳帽與 H/L 觸發選擇。
- 目前實際編譯程式使用：GPIO5/6 為 HC-SR04、GPIO7 為繼電器、GPIO8–12 為兩顆 VL53L0X、GPIO4 為舊伺服訊號。

不能由現有照片確認，因此必須現場量測：

- 牆端電纜及鼓風機剪線後每條芯線的 L、N、PE 身分。不可只看顏色，應以插頭腳位連續性確認。
- 實際到貨繼電器模組背面銅箔、焊點、爬電距離及螺絲端子額定。
- 兩顆 VL53L0X 模組的實際型號與供電端標示。現有感測器已可讀值時，供電線保持原樣，不改成照片無法證明的電壓。
- ESP32 開發板 `5V/VIN` 排針的實體位置；依你手上板子的絲印，不依網路通用腳位圖。

## 2. 先拆除的現有線

斷開牆端插頭並確認無電後：

1. 拆除伺服馬達所有三條線：舊 GPIO4 訊號、伺服正電、伺服 GND；GPIO4 留空。
2. 拆除目前繼電器 `COM`、`NO`、`NC` 上的所有 5V 或伺服線。
3. 不拆感測器的 GPIO5、6、8、9、10、11、12 與既有供電線，除非現場核對發現和下表不同。
4. 低壓側保留 GPIO7→`IN`、5V→`DC+`、GND→`DC-`；H/L 跳帽放在 `H`。
5. `DC+↔JD+` 及 `DC-↔JD-` 兩個跳帽保持安裝。

> 完成後，繼電器 `COM/NO/NC` 必須與 ESP32、5V、感測器及伺服線完全隔離；這三端將改作 110V。

## 3. 110V 端子逐點接線

| 線號 | 起點 | 終點 | 線材／要求 |
|---|---|---|---|
| AC-01 | 市電 L | ≤30mA漏電保護器 → 雙極總開關 → `T5A/250V`慢熔保險絲 | AWG16／1.25mm²以上 |
| AC-02 | 保險絲輸出 | S-50-5 `L` | 同上 |
| AC-03 | 保險絲輸出 | 繼電器 `COM`（照片中間端子） | 同上 |
| AC-04 | 繼電器 `NO`（照片上端子） | 鼓風機 L | 同上；`NC`不用 |
| AC-05 | 市電 N 經雙極總開關 | S-50-5 `N` | 不經繼電器 |
| AC-06 | 市電 N 經雙極總開關 | 鼓風機 N | 不經繼電器 |
| AC-07 | 市電 PE | S-50-5 `FG/⏚` | 黃綠線；不得串開關或保險絲 |
| AC-08 | 市電 PE | 控制箱與所有可觸金屬件 | 使用環形端子、星形墊片及專用接地螺絲 |
| AC-09 | 市電 PE | 鼓風機 PE | 只有原鼓風機電纜確有PE芯線時接；不得自行把 N 當 PE |
| AC-10 | MOV一端 | 繼電器後的鼓風機 L | `V150LA20AP`或同級150VAC MOV |
| AC-11 | MOV另一端 | 鼓風機 N | MOV 位於 T5A 保護下游 |

S-50-5 通電前把 110/220 切換器撥到 `110V`。第一次通電時先不接 ESP32，在 `+V/-V` 間量測並將旋鈕調成 `5.0±0.1V`。

## 4. 5V 與繼電器控制接線

| 線號 | 起點 | 終點 | 備註 |
|---|---|---|---|
| DC-01 | S-50-5 `+V` | `F2 2A`低壓保險絲 | S-50-5可輸出10A，F2保護細線與控制板 |
| DC-02 | F2輸出 | +5V分配端子 | 建議紅色端子排 |
| DC-03 | S-50-5 `-V` | 0V/GND分配端子 | 建議黑色端子排 |
| DC-04 | +5V分配端子 | 可拔式 `EXT-5V` 跳線→ESP32 `5V/VIN` | 插電腦USB前先拔跳線 |
| DC-05 | 0V/GND端子 | ESP32 `GND` | 全部低壓共地 |
| DC-06 | +5V分配端子 | 繼電器 `DC+` | `DC+↔JD+`跳帽保持 |
| DC-07 | 0V/GND端子 | 繼電器 `DC-` | `DC-↔JD-`跳帽保持 |
| SIG-01 | ESP32 `GPIO7` | 繼電器 `IN` | H/L跳帽設為`H`；HIGH=吸合 |

ESP32附近的 +5V/GND 間加 `470µF/10V` 電解電容（注意極性）及 `0.1µF`陶瓷電容。

## 6. 無電與上電檢查順序

1. 無電狀態確認 `COM-NO` 開路、`COM-NC` 導通；模組低壓吸合後結果相反。
2. 量測 110V 端子對低壓 GND 不導通；檢查背面高低壓銅箔無焊錫橋。
3. 只開 S-50-5，確認 5.0V、極性正確，再插 `EXT-5V`。
4. 先不接鼓風機，以GPIO7或感測器條件測試繼電器：啟動時紅色動作燈亮且 `COM-NO` 導通。
5. 先以小功率110V燈泡接在鼓風機位置測試；確認斷電、ESP32重啟及感測器故障都使輸出OFF。
6. 最後接鼓風機，量測啟動與運轉電流，連續啟停20次並運轉30分鐘，檢查端子、繼電器、電源與導線無異常溫升。

## 7. 目前韌體與接線的關係

目前 `main/main.c` 的 GPIO7 與 `H`觸發接法相容，但程式仍包含伺服上電等待與解除後600ms回位流程。因此完成本接線後，正式接110V鼓風機前，仍需把實際編譯的 `main/main.c` 改成「三顆皆active即持續ON；任一顆連續3次clear或讀取失敗即OFF」，不能只改IDE中開啟的 `.ino`。
